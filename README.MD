# ZURF

### A Youtube Player in the Terminal
  Does Chrome take up too much memory? Too many clicks and buttons and mouse waves to open up your browser, search a youtube video, resize the window, and press play?? Do you just want to watch AI doomsday videos in your tmux pane??? Then this app is for you. Search and play YT videos in your terminal with just a few commands. 

###  Goals and Motivations
  The goal is to have a TUI that allows users to search and play YT videos in their terminal, regardless of OS. Navigation is to be done with vim keybings 'h-j-k-l'. The app itself should be preformant enough that it's not a pain to use, meaning no buffering or long wait times, should return an accurate list of videos with the correct info (creator, playtime, thumbnail), and overall similar to the browser experience (minus the ram usage chrome!). Lastly, this is a personal project, so the most important goal is personal. It's to have fun and learn some stuff. I will optimize for enjoyment and curiosity when given the oppurtunity. 

  The reason I chose this as a project is because I tried out Omarchy and it had so many CLI apps that were really cool. Youtube is my main source of entertainment, especially while I'm coding or working or pretending to code or work. I think having a YT player in the terminal would be pretty neat. I know there are other alternatives, but hey, why not give a crack at it. I hope to learn a little bit more about the terminal, what processes are actually running, and how these apps I enjoy so much actually work. I also need a project to try out Zig. Not a whole lot of experience with the language but I'm interested. Bun and Ghostty are both built with Zig and I've heard a lot of positives.
